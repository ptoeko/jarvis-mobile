# Как установить JARVIS на Android

Есть два способа. Основной — **APK**: обычное приложение Android. Запасной — **веб-приложение** из Chrome. Выберите один: у этих вариантов **разные хранилища данных**, и записи из одного не видны в другом.

## Способ 1. APK (основной)

Требования: Android 7 или новее, обновлённые «Android System WebView» и «Chrome» (Play Маркет → «Обновить»).

1. На телефоне откройте страницу выпусков: `https://github.com/<ваш-логин>/jarvis-mobile/releases/latest`.
2. В разделе **Assets** нажмите **JARVIS-<версия>.apk**. Файл скачается в «Загрузки».
3. Откройте скачанный файл (уведомление о загрузке или приложение «Файлы» → «Загрузки»).
4. Android предупредит, что установка из этого источника запрещена. Нажмите **Настройки** → включите **Разрешить из этого источника** → вернитесь назад.
5. Нажмите **Установить**. Если появится окно Google Play Защиты о неизвестном разработчике, нажмите **Всё равно установить**. Приложение не из Play Маркета, поэтому Google его не знает. Это ожидаемо.
6. Нажмите **Открыть**. На главном экране появится иконка **JARVIS**.

Файл `JARVIS-<версия>-test.apk` — отладочная версия для автоматических проверок. Устанавливать её не нужно.

### Обновление

Скачайте новый APK со страницы выпусков и установите его поверх старого. **Не удаляйте старую версию**: при удалении приложения Android удаляет и его данные. Новая версия ставится поверх, только если подписана тем же ключом. Ключ хранится в секретах репозитория, а его резервная копия — у владельца проекта.

### Где хранятся данные

- Заметки и реестр хранятся во внутренней памяти приложения на телефоне и никуда не отправляются.
- В облачную резервную копию Google они не попадают — это отключено намеренно.
- Данные удаляются при удалении приложения или при «Очистить данные» в настройках Android.
- Экспорт CSV: на экране «Реестр» нажмите «Экспорт CSV» → «Сохранить CSV». Откроется окно Android «Сохранить» — выберите папку (например, «Загрузки») и нажмите «Сохранить».

## Способ 2. Веб-приложение (запасной)

1. Откройте в Chrome: `https://<ваш-логин>.github.io/jarvis-mobile/`.
2. Меню Chrome ⋮ → **Установить приложение** (или **Добавить на главный экран**) → **Установить**.
3. Иконка JARVIS появится на главном экране. Приложение работает без интернета после первого открытия.

Данные хранятся в Chrome. Они удаляются, если очистить данные сайта в Chrome.

## Если что-то не работает

- **Белый экран или сообщение «нужна более новая версия»** — обновите «Android System WebView» и «Chrome» в Play Маркете.
- **Не устанавливается поверх старой версии («конфликт пакетов»)** — новая версия подписана другим ключом. Не удаляйте старую, сначала сообщите разработчику: при удалении пропадут данные.
- **Файл CSV открывается в Excel «кракозябрами»** — откройте его через «Данные → Из текста/CSV» с кодировкой UTF-8. Если отметки превратились в числа или даты, при импорте выберите для столбцов формат «Текст».
