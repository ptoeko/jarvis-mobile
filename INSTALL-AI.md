# Подключение «ИИ агента» к JARVIS — пошагово

Делается один раз, на компьютере, примерно за 30–40 минут. Ключ ИИ хранится только в секретах GitHub и на посреднике Cloudflare — в приложение и в переписку он не попадает. В JARVIS нигде не показывается название модели — только «ИИ агент».

Что понадобится: Google-аккаунт (Gmail), доступ к github.com/ptoeko/jarvis-mobile, файл `JARVIS_ACCESS_CODE.txt` (код доступа, прислан в чате). **Банковская карта для Gemini не нужна.**

Агент может работать на одном из двух поставщиков ИИ — **Gemini** (Google) или **Anthropic**. В приложении это не видно: там всегда «ИИ агент». Если в GitHub задан ключ Gemini, используется Gemini. Переключение — только сменой секрета и повторной публикацией посредника, новая версия приложения не нужна.

---

## Шаг 1. Ключ Gemini (≈5 мин, бесплатно)

1. Откройте **aistudio.google.com** в Chrome → войдите своим Google-аккаунтом → примите условия.
2. Слева **Get API key** (или **API keys**) → **Create API key** → если спросит проект, выберите предложенный или **Create project** → **скопируйте ключ** (начинается с `AIza…`).
3. Ключ **никому не пересылайте и не вставляйте в чат** — сразу переходите к шагу 2.

Бесплатный уровень: карта не нужна, есть лимит запросов в минуту и в день. При превышении агент ответит «Исчерпан лимит запросов…» и заработает позже, приложение продолжит работать без ИИ. **Важно:** на бесплатном уровне Google может использовать отправленные тексты и файлы для улучшения своих продуктов, их могут просматривать сотрудники. Поэтому — только учебные данные. Чтобы это отключить и снять лимиты, в AI Studio можно включить оплату (**Billing**, предоплата от 5 $) и задать месячный лимит расходов (**Spend → Monthly spend cap**).

Работает из Бангладеш; из России Gemini API недоступен.

## Шаг 1 (вариант). Ключ Anthropic

Если позже захотите вернуться к Anthropic:

1. Откройте **console.anthropic.com** → зарегистрируйтесь (почта, телефон).
2. **Оплату можно отложить.** Ключ создаётся и без денег на балансе: всё настроится, приложение будет работать как обычно, а ИИ агент начнёт отвечать после пополнения (до этого он вежливо сообщит «Баланс ИИ агента не пополнен», а «В реестр» заполнит поля по правилам).
   Когда решите пользоваться: **Settings → Billing** → карта → пополнить, например, на **5–10 $**. Подписки и ежемесячной платы нет — деньги списываются только за запросы, когда вы пишете агенту.
3. Там же **Limits / Spend limit** → месячный лимит, например **10 $**: больше этой суммы не спишется.
4. **API Keys → Create Key** → назовите `jarvis` → **скопируйте ключ** (начинается с `sk-ant-…`). Он показывается один раз.
5. Ключ **никому не пересылайте и не вставляйте в чат** — сразу переходите к шагу 3.

## Шаг 2. Cloudflare (≈10 мин, бесплатно)

1. Откройте **dash.cloudflare.com** → зарегистрируйтесь.
2. Слева **Workers & Pages** → откройте раздел один раз; если предложат выбрать поддомен `*.workers.dev` — придумайте короткое имя (например, `ptoeko`) и сохраните.
3. **Account ID**: на странице Workers & Pages справа есть «Account ID» → скопируйте.
4. **API-токен**: правый верхний угол → **My Profile → API Tokens → Create Token** → шаблон **«Edit Cloudflare Workers»** → **Use template** → внизу **Continue to summary → Create Token** → скопируйте токен.

## Шаг 3. Секреты в GitHub (≈5 мин)

github.com/ptoeko/jarvis-mobile → **Settings → Secrets and variables → Actions → New repository secret**. Создайте секреты (имя — точно как здесь). Если какие-то уже созданы раньше — пропустите их.

| Name | Secret (что вставить) |
|---|---|
| `GEMINI_API_KEY` | ключ Gemini из шага 1 (`AIza…`) |
| `CLOUDFLARE_API_TOKEN` | токен из шага 2.4 |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID из шага 2.3 |
| `JARVIS_ACCESS_CODE` | содержимое файла `JARVIS_ACCESS_CODE.txt` |

## Шаг 4. Публикация посредника (≈3 мин)

1. Слейте запрос «ИИ агент на Gemini» (Pull requests → запрос → **Merge pull request** → **Confirm merge**), если ещё не слили.
2. **Actions → «Посредник ИИ агента» → Run workflow → Run workflow**.
3. Через 1–2 минуты откройте этот запуск: вверху будет зелёная галочка и надпись **«Адрес посредника для приложения: https://jarvis-agent.…workers.dev»**. Скопируйте адрес. Если красный крестик — на странице написано, какого секрета не хватает.

Посредник сам выберет подходящую модель Gemini и проверит, что ИИ отвечает (несколько маленьких запросов). Жёлтое предупреждение «Лимит запросов ИИ» или «Баланс ИИ не пополнен» — это нормально: посредник готов и заработает сам, перезапускать не нужно.

Если адрес посредника уже был введён в телефоне раньше — шаг 5 не нужен: адрес и код доступа не меняются.

## Шаг 5. Подключение в телефоне (1 мин)

JARVIS → **Настройки → ИИ агент**:
- **Адрес посредника** — адрес из шага 4;
- **Код доступа** — содержимое `JARVIS_ACCESS_CODE.txt`;
- **Подключить**. В шапке появится «ИИ агент подключён».

## Что уходит наружу

Сообщения, которые вы отправляете в «Диалоге», последние 20 сообщений переписки, фото и PDF из последнего сообщения, тексты заметок «В реестр» — обрабатываются внешним ИИ-сервисом (Gemini или Anthropic). На бесплатном уровне Gemini Google может использовать эти данные для улучшения своих продуктов. Реестр, резервные копии и остальные файлы остаются на телефоне. **Реальные документы и замечания с площадки — только с разрешения работодателя.**

## Расходы

Оплата — по объёму текста. Для личной работы обычно несколько долларов в месяц. Месячный лимит из шага 1.3 гарантирует, что больше заданной суммы не спишется. Остаток и расходы видны в console.anthropic.com → Billing / Usage.

## Если что-то не работает

- **«Неверный код доступа»** — код в приложении не совпадает с секретом `JARVIS_ACCESS_CODE`. Скопируйте ещё раз, без пробелов.
- **«Ключ ИИ недействителен»** — создайте новый ключ, обновите секрет `GEMINI_API_KEY` (или `ANTHROPIC_API_KEY`) → снова **Run workflow**.
- **«Исчерпан лимит запросов…»** — бесплатный лимит Gemini на минуту или день; подождите (дневной обновляется около 13:00 по Дакке) или включите оплату в AI Studio.
- **«Недоступен из региона…»** — сервер Cloudflare обратился к Google из страны, где Gemini не работает. Повторите позже; если не проходит — сообщите разработчику.
- **Вернуться на Anthropic** — удалите секрет `GEMINI_API_KEY`, задайте `ANTHROPIC_API_KEY` → **Run workflow**.
- **«Исчерпан лимит расходов»** — увеличьте лимит в console.anthropic.com или подождите начала месяца.
- **«Нет связи с ИИ агентом»** — нет интернета на телефоне.
- Отключить ИИ агента: **Настройки → ИИ агент → Отключить** (вернётся демо-режим, данные не пропадут).
- Сменить код доступа: новый секрет `JARVIS_ACCESS_CODE` → **Run workflow** → ввести новый код в приложении.
